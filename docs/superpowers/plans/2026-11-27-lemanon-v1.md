# Lemanon v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish an installable `$lemanon` skill that initializes and maintains a safe, generic project knowledge base.

**Architecture:** A single mode-based skill routes agentic lifecycle work to focused references. A dependency-free Python helper performs deterministic initialization and structural audits; Markdown assets remain usable after the skill is removed.

**Tech Stack:** Markdown, YAML metadata, Python 3.10+ standard library, `unittest`, Git, GitHub.

**Spec:** `docs/superpowers/specs/2026-11-27-lemanon-design.md`

## Global Constraints

- The public name, repository, and invocation name are `Lemanon`, `lemanon`, and `$lemanon`.
- The supported modes are exactly `init`, `onboard`, `handoff`, `receive`, `close`, and `audit`.
- Existing files are never silently replaced; proposed changes to existing rules are reported separately.
- Generated knowledge remains plain Markdown and works without Lemanon.
- No database, daemon, network service, semantic search, chat ingestion, or graphical UI is included.
- No operation implies authority to merge, push, delete, publish, run remote work, or accept unverified claims.
- Tests and validation must run on a user-approved remote system, never on the Mac.
- Public examples and fixtures must be synthetic and contain no private project names, personal paths, credentials, or private infrastructure.

## Review Focus

- Existing `AGENTS.md`: initialization must preserve it byte-for-byte and emit a proposed include block.
- Repeated initialization: the second run must be idempotent and report no overwritten files.
- Partially initialized project: missing files must be added without replacing customized files.
- Untrusted handoff: receive guidance must require independent verification before shared promotion.
- Suspicious repository content: audit must report secrets, absolute personal paths, oversized artifacts, and broken internal links without modifying them.
