# Lemanon Design

Lemanon is an installable, Git-native, Markdown-first continuity skill for
long-running agent projects. The approved public interface is `$lemanon` with
the modes `init`, `onboard`, `handoff`, `receive`, `close`, and `audit`.

The generated knowledge base separates stable project scope, authoritative
current status, roadmap, sources, history, lessons, decisions, work records,
evidence, producer-owned handoffs, shared verified handoffs, guides, source
catalogs, archives, and templates. Initialization is progressive and never
silently replaces existing project rules or knowledge files.

Lemanon stores no raw datasets, logs, weights, secrets, build products, or
large generated artifacts. It grants no implicit authority to merge, push,
delete, publish, run remote work, or accept another agent's claims.

The first release is one mode-based Codex skill with progressive references,
standard-library deterministic helpers, synthetic examples, and a thin Claude
Code adapter. It has no database, daemon, semantic search, automatic chat
ingestion, or graphical interface. The proposed license is MIT.

The full reviewed design is preserved at `outputs/Lemanon-design.md` in the
design workspace and will be copied into the repository when implementation
begins.
