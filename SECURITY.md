# Security policy

## Supported version

Security fixes currently target the latest commit on the default branch.

## Reporting a vulnerability

Do not disclose suspected credential exposure, unsafe file mutation, path
escape, or other security-sensitive behavior in a public issue. Report it
privately through GitHub's private vulnerability reporting when available, or
contact the repository owner privately through the linked GitHub profile.

Include the affected commit, minimum reproduction, observed impact, and whether
the report contains secrets. Replace real credentials and personal paths with
synthetic values. Lemanon should never require raw private project data for a
security report.
