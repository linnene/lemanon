# Knowledge base rules

- Keep current truth in `STATUS.md`; move superseded state to `HISTORY.md`.
- Separate verified facts, inference, proposals, and unfinished work.
- Record exact commits and evidence locations for consequential conclusions.
- Keep raw data, logs, credentials, build products, and large generated
  artifacts in their owning systems.
- Producer handoffs remain producer-owned. Promote only independently verified
  cross-agent state to `handoffs/shared/`.
