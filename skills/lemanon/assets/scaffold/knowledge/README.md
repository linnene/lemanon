# Project knowledge base

This directory stores durable project context and the smallest useful view of
current state. It complements Git, source artifacts, issue trackers, and
external evidence; it does not replace them.

## Start here

- `PROJECT.md` — purpose, boundaries, and success.
- `STATUS.md` — current facts, blockers, and next work.
- `ROADMAP.md` — future phases, gates, and authorization.
- `SOURCES.md` — where code, evidence, and assets live.
- `HISTORY.md` — phase changes and superseded state.
- `LESSONS.md` — failures and reversed conclusions.
- `handoffs/` — agent and session recovery records.
